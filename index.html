How I test

Same process every time, so results can be compared and checked by anyone.

  1. Claim received

    A popular strategy, paraphrased as an idea. Claims are tested, not people.

  2. Rules defined

    Exact entry and exit rules, coins, timeframe and period, written down before any result is seen.

  3. Backtest on real data

    Historical market data, trading fees included, losing trades kept in.

  4. Verdict logged

    A stamp, the numbers behind it, and the full Python code published on GitHub.
